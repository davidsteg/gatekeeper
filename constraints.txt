# Pins for the Python that is left around gatekeeper (the binary itself is
# the Rust crate in rust/, locked by rust/Cargo.lock):
#
# * The image's script venv (Dockerfile, `scripts` stage), which holds only
#   what the vendored google_api.py needs. google-auth pulls in
#   cryptography; pinning it keeps two builds of the same commit on the same
#   version, and `pip-audit` in CI checks the version that actually ships.
#   Deliberately not a full `pip freeze`: the image is built for amd64 and
#   arm64, and a transitive lock resolved on one is not guaranteed to match
#   the other's wheels.
# * CI: the interop tests that drive the Rust server with the official MCP
#   SDK client (`rust` job), and PyYAML for the pytest suite (`tests` job).
#
